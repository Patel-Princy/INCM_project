# Phase 5F — Reference Verification Record

**Branch:** `ashish-work` · **Base commit:** `5509ddd`
**Method:** Every DOI was resolved against the Crossref REST API (`api.crossref.org/works/<DOI>`). Title, author list, container, volume/issue/pages and issue date were compared with the manuscript citation. For journal articles, the abstract was retrieved from PubMed (NCBI E-utilities `esearch` + `efetch`, query `<DOI>[doi]`) and the claim attributed to the paper was checked against the abstract. Books and technical documents were checked against the publisher or Allen Institute record. Full texts were **not** read for every source. Where a claim goes beyond the abstract, this is stated in the "Claims supported" column and the confidence is lowered.

**Status codes**

| Code | Meaning |
| :---: | :--- |
| **V** | Verified: bibliographic data correct, DOI resolves, claim supported by abstract or publisher record |
| **V\*** | Verified after correction (the manuscript entry contained an error that has been fixed) |
| **V-ctx** | Verified bibliographically; used only as general/theoretical context (claim not abstract-checkable, e.g. textbook) |
| **V-med** | Verified bibliographically; claim supported but only partially explicit in the abstract (medium confidence) |
| **U** | Unresolved: some element could not be verified and is reported as such |
| **D** | Considered and dropped (not cited) |
